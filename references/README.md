### Что снял с примеров (принципы вёрстки Точки)

- **Каркас десктопа:** экосистемная шапка ~74 (лого · Главная/Платежи/Сервисы · правый
  кластер) → левая колонка ~280 (кнопка «назад», крошки «Онлайн-бухгалтерия ›», H1 +
  сабтайтл режима «УСН „Доходы“ — 6%», список второстепенных ссылок) → центр 720 из
  **белых карточек** на сером фоне. Сверху контента — `PageAction`-чипы.
- **Виджет «Задачи»** на этой Главной = единый агрегат «Текущих задач нет» — ровно тот
  антипаттерн-«ведро», от которого мы уходим. Наш поток событий его заменяет.
- **Экран платежа — готовый паттерн, к которому ведёт каждое платёжное событие:** крупная
  сумма → дедлайн (в просрочке краснеет + строка про пени) → чип «Изменить сумму» →
  карточка-навигатор «Расчёт налогов / Почему такая сумма?» → «Реквизиты / ЕНС» →
  селектор «Со счёта» → закреплённый футер «Уже уплачено» + «Уплатить» (фиолетовая).
- **Тревога локальна:** решается на карточке платежа (красный дедлайн, строка-пояснение,
  розовый алерт-баннер «С задачей» с ценой ошибки), не кричит с Главной.
- **Онбординг** = фиолетовый виджет-баннер с прогрессом «0 из 8» + нумерованные шаги;
  прогресс-состояние, не блокирует вход.
- Способы упаковки из DS: 2-колоночные плитки, cell-списки с иконками в кружках.
- **Экран платежа (ОБ | Платежи):** узел `55747-69838` — крупная сумма + дедлайн →
  чип «Изменить сумму» → «Расчёт налогов / Почему такая сумма?» → «Реквизиты / ЕНС» →
  селектор счёта → футер `Уже уплачено` + `Уплатить`.
